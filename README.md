# 合租管家

一个无需后端即可体验的合租生活管理应用，包含体验登录、AA账单、自动结算、家务排班、公共采购、抄表与报修。

## 使用方式

直接打开 `index.html`，或通过 GitHub Pages 访问。登录页可填写示例信息，也可以点击“使用体验账号”。

所有修改保存在浏览器 `localStorage` 中。可以在“我的”页面恢复初始示例数据。

## 文件

- `index.html`：页面结构和登录入口
- `styles.css`：响应式界面样式
- `app.js`：示例数据、账单计算和交互逻辑
- `assets/hezuguanjia-logo.png`：品牌 Logo

## 说明

当前版本是纯前端演示，不包含真实短信认证、服务器或数据库。正式多人协作需要接入后端身份认证和数据存储。
